# HayphyrOS

Sistema Linux leve e otimizado para jogos, montado do zero a partir do Arch Linux.
Projeto de estudo para entender como um sistema operacional funciona.

## Objetivos
- Sistema minimalista, só com o necessário
- Foco em desempenho e jogos (Steam, Proton, Gamescope)
- Entender cada peça: bootloader, kernel, init, userspace

## Hardware de teste
- Ryzen 5 5600GT (vídeo integrado Vega)
- 16 GB RAM
- NVMe 256 GB (Linux) + NVMe separado (Windows)

## Status
Em desenvolvimento. Testes em máquina virtual antes da instalação real.

## Estrutura
- `install/` scripts de instalação
- `configs/` arquivos de configuração
- `packages.txt` lista de pacotes
- `docs/` anotações do que aprendi
